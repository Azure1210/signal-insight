# 项目根路径定位（标记文件法）

## 背景：为什么不用 `parents[2]`

`config.py` 一开始用 `Path(__file__).resolve().parents[2]` 定位项目根。
这个写法依赖 `config.py` 恰好位于 `src/signal_insight/` 这一层：
一旦文件移动或目录层级变化，`PROJECT_ROOT` 就会算错，
而且错误往往延迟到真正读取 `data/` 时才暴露，很难排查。

因此改用「标记文件法」：在项目根放一个约定文件 `signal.workspace`，
`config.py` 从自己所在目录逐级向上找这个文件，找到的目录就是项目根。
这样不管 `config.py` 以后放到多深，都能准确定位。

## 操作步骤

### 第 1 步：在项目根目录建立标记文件

在项目根目录（`signal-insight/`）新建一个名为 `signal.workspace` 的空文件。
它的「存在」本身就是标记，内容不影响定位，但建议写一行说明避免误删。

> 注意：这个文件需要提交到 git（不要写进 `.gitignore`），
> 否则别人克隆项目后会因为找不到标记文件而报错。

### 第 2 步：在 `config.py` 中定义查找函数

```python
from pathlib import Path

# 项目根的标记文件
WORKSPACE_MARKER = "signal.workspace"


def find_project_root(marker: str = WORKSPACE_MARKER) -> Path:
    """从 config.py 所在目录逐级向上查找含 marker 的目录，作为项目根路径。"""
    for parent in Path(__file__).resolve().parents:
        if (parent / marker).exists():
            return parent
    raise FileNotFoundError(
        f"未找到项目根标记文件 {marker!r}，请确认它存在于项目根目录"
    )


PROJECT_ROOT = find_project_root()
```

### 第 3 步：验证

在 notebook 或终端里：

```python
from signal_insight import config

print(config.PROJECT_ROOT)                       # 项目根目录
print(config.DATA_DIR)                           # <项目根>/data
print((config.PROJECT_ROOT / "signal.workspace").exists())  # True
```

或在项目根目录打开终端执行：

```
python -c "from signal_insight import config; print(config.PROJECT_ROOT)"
```

## 工作原理

`Path(__file__).resolve().parents` 会依次给出 `config.py` 的各级父目录：
`signal_insight` → `src` → 项目根 → `Desktop` → …，一路向上直到文件系统根。
`find_project_root` 从最近的父目录开始，找到第一个含有 `signal.workspace`
的目录就立即返回，因此只要根目录有该标记文件，就一定找得到。

## 注意事项

1. `signal.workspace` 必须放在项目根目录，且不要随便删除或改名。
2. 找不到标记文件时，函数会抛出 `FileNotFoundError` 并给出提示，
   而不是默默算出一个错误路径——宁可尽早报错，也不要静默出错。
3. 不要在子目录里也放同名文件，否则会优先命中离 `config.py` 最近的那一级。
