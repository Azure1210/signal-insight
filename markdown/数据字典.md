# 数据字典

可信度只有三档：**已验证**（用数据证明过）、**推测**（有依据但没验证）、**未知**。

## ods_signal（原始信令，532,828 行）

| 字段             | 含义                                          | 可信度             | 依据                                               |
| ---------------- | --------------------------------------------- | ------------------ | -------------------------------------------------- |
| timestamp        | 事件时间，UTC 毫秒；+8 小时为北京时间         | 已验证             | 小时分布符合作息（D01）                            |
| imsi             | 用户标识，**完整 18 位才是一个人**            | 已验证             | 与手机号一一对应；前 15 位不成立（D02 需求卡 2.5） |
| lac_id / cell_id | 位置区 / 小区编号；库里是浮点数（列里有空值） | 推测               | D03 与基站表关联验证                               |
| phone            | 脱敏手机号                                    | 已验证             | 14 位；6666 为占位值；明细表不保留                 |
| timestamp1       | 第二个时间戳，与 timestamp 中位相差 23 毫秒   | 已验证             | 不使用                                             |
| tmp0 / tmp1      | 无内容                                        | 已验证             | 全部是空值 / 空格                                  |
| nid              | 事件类型编码                                  | 推测（字典不可信） | D02 需求卡 2.8                                     |
| npid             | 4 位掩码编号                                  | 未知               | 形如 `#*#6137`                                     |

## dwd_signal（清洗后的明细，515,931 行，只含 10-03）

| 字段             | 含义                                                         |
| ---------------- | ------------------------------------------------------------ |
| imsi             | 18 位 IMSI                                                   |
| ts               | 北京时间，文本 `YYYY-MM-DD HH:MM:SS.fff`（SQLite 没有日期类型，读回时 `parse_dates=["ts"]`） |
| dt               | 日期分区 `2018-10-03`                                        |
| lac_id / cell_id | 整数                                                         |
| nid              | 原样保留，含义未知                                           |
| lac_cell         | `lac_id-cell_id`，关联基站表用                               |

**注意**：`dwd_signal` 是事件触发的记录，不是定时采样（D02 需求卡 2.10）。
