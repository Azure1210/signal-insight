# 需求改写

甲方原话：“国庆期间我们想了解一下区里的夜间经济情况，你们运营商有数据，帮我们看看。”

D04 推断出样本口径：**2018 年 10 月 3 日傍晚后到访沈阳西塔的中国移动用户，及其全天信令。**
（推断依据见 D04 需求卡 4.5、DQ-15、DQ-16；圈选条件待数据提供方确认。）

所以需求改写为：

> 国庆傍晚来西塔的人，几点来、待多久、从哪来、还去了哪。

| 能回答（D06–D10 做）                         | 不能回答（报告里写明原因）                                   |
| -------------------------------------------- | ------------------------------------------------------------ |
| 国庆夜间到访西塔的人，几点来、待多久、几点走 | 全市的夜间人流（样本是按西塔圈选的）                         |
| 这些人从哪里来（过夜地在哪个区、离西塔多远） | 工作日与节假日的对比（只有 1 天，还是假期）                  |
| 来西塔之前还去过哪些商圈（太原街、中街）     | 通勤、职住分析（假期没有通勤）                               |
| 西塔的“客群”能分成哪几类                     | 精确的交通方式（信令定位精度只有几百米）                     |
|                                              | 联通、电信用户的情况；总人数（只有移动用户，需按市场份额扩样） |
