## 0 字体：课程只用开源字体

**这是一条合规红线，不是审美偏好。**

字体是受著作权保护的软件。微软雅黑、苹方、黑体、宋体、Times New Roman 都是**商业字体**：
系统里装着是因为随操作系统授权，但把指定了这些字体的课件、报告、PPT、图片分发出去，
授权范围就不一定覆盖得到了。国内已经有不少企业因为宣传物料里用了商业字体被追责的案例。
学生把课程作品放进简历或作品集时，这件事尤其要紧——那是对外公开的商业用途。

所以本课程的图表、Word 报告、HTML 页面**只写开源字体的名字**，代码里一个商业字体名都不出现。

| 角色 | 课程选用 | 替代的是 | 许可证 |
|---|---|---|---|
| 中文黑体（图表、标题） | **Source Han Sans SC**（思源黑体） | 黑体 / 微软雅黑 / 苹方 | SIL Open Font License 1.1，可免费商用 |
| 中文衬线（Word 报告正文） | **Noto Serif CJK SC**（思源宋体） | 宋体 / SimSun | SIL Open Font License 1.1，可免费商用 |
| 西文衬线（正文西文、数字） | **TeX Gyre Termes** | Times New Roman | GUST Font License（等同 OFL），可免费商用 |
| 西文兜底（负号、上下标） | **DejaVu Sans** | — | Bitstream Vera 许可，可免费商用；matplotlib 自带 |

### 一个坑：同一套字体有三个名字

思源系列是 Adobe 和 Google 联合开发的，两家各自发布，名字不一样，但**是同一套字形**：

```
思源黑体 = Source Han Sans SC = Noto Sans CJK SC = Noto Sans SC
思源宋体 = Source Han Serif SC = Noto Serif CJK SC = Noto Serif SC
```

所以代码里要把别名一起列上，哪台机器装了哪个发行版都能用。只写一个名字，
换台电脑就变方框——这是学生最常遇到的"在我这儿好好的"类问题。

另外 Linux 发行版常常只装了 `Noto Sans CJK JP`（泛 CJK 合集里的日文命名），
它**覆盖简体中文字形**，少数汉字（直、骨、返……）是日文写法。应急可用，正式出图建议装 SC 版。

### 检查和安装

运行 notebook 第一格（D02 起是 `viz.apply_theme()`）：它返回本机实际生效的字体列表；一个中文字体都没有时会打印“⚠️ 本机没有课程用的开源中文字体”。

安装：从思源字体的官方发布页（Adobe 的 source-han-sans / source-han-serif 仓库，或 Google Fonts 的 Noto Sans SC / Noto Serif SC）下载安装，装完重启 Jupyter 内核。

装不全也能上课：matplotlib 会退回 DejaVu Sans，**西文和数字正常，中文变方框**。
这时候要装字体，**不要**改成系统自带的中文字体顶替——那正是这一节要避免的事。

### Word 报告的额外注意

Word 文档里字体名是**写死在文件里**的，收到文件的人机器上没有这个字体就会回退到系统字体，
排版会变。所以交付 Word 时要么一起给字体安装包，要么**导出 PDF**（PDF 会把用到的字形嵌进去，
对方没装字体也显示正确）。本项目 `tools/preflight.py` 的交付自查里有这一条提醒。

## 2 颜色

原则：**灰色打底，一种颜色强调一件事，红色只表示警示。**

| 用途 | 颜色 | 代码 |
|---|---|---|
| 主色（强调的对象） | #1D6FA5 | `MAIN` |
| 主色浅 / 中 | #DCEAF5 / #7FB3D9 | `MAIN_LIGHT` / `MAIN_MID` |
| 背景对象 | #C4CAD3 | `GRAY` |
| 警示、不通过 | #D64545 | `RED` |
| 警告 | #B7791F | `AMBER` |
| 通过 | #3B8C66 | — |
| 正文 / 次要文字 / 来源行 | #1F2937 / #6B7280 / #9CA3AF | `INK` / `MUTED` / `FAINT` |

**固定映射**（所有图、报告、平台一致）：

- 区域：西塔 #1D6FA5，太原街商圈 #D9822B，中街商圈 #3B8C66，沈阳北站 #7A5EA8，世博园 #B04A6A，棋盘山 #6B7F2A；配置里新增的区域按名称哈希取备用色，每次都一样。用 `viz.AREA_COLOR[名称]`。
- 客群：市内来访 = 主色，周边居民 = 主色浅，外地来客 = 橙，**过夜地不明永远是灰色**（它不是一类人，是我们不知道）。用 `viz.SEG_COLOR[名称]`。
- 状态：通过绿、警告黄、不通过红；模拟分区用斜线填充并打水印。

不用彩虹色阶。连续数值用单色渐变（浅→深）；跨数量级的（如六边形热力）用对数色阶，并在色条上标出实际数值（5、10、30、100……），不标 10¹、10²。

## 4 选图：问题决定图形

| 要回答的问题 | 用 | 不用 |
|---|---|---|
| 随时间怎么变 | 折线（小时、日期） | 柱状图堆满 24 根 |
| 几类之间比大小 | 横向条形图，按大小排序 | 饼图（超过 5 类时） |
| 构成（占比） | 条形图 + 百分比标注；类别 ≤ 5 时可用堆叠条 | 3D 饼图、环形图 |
| 分布 | 直方图、ECDF（累计分布） | 只给平均数 |
| 两个指标的关系 | 散点图 | 双轴折线 |
| 空间分布 | 六边形热力 + 区县边界 | 点太多的散点地图 |
| 矩阵（A 与 B 的关系） | 热力矩阵，格子里写数字 | 和弦图 |
| 前后对比 | 哑铃图、斜率图 | 两张独立的图 |
| 参数影响 | 多条折线，选用的参数加粗并圈出 | 表格堆数字 |

## 5 禁止项

1. **双 Y 轴**：两条线的交点、高低关系全由刻度决定，容易误导。改成上下两个面板，共用横轴。
2. **3D 图**：透视让大小失真。
3. **超过 5 块的饼图**：人眼比较角度很差。
4. **截断的纵轴柱状图**：柱子的长度就是数值，纵轴必须从 0 开始（折线图可以不从 0 开始，但要说明）。
5. **图例超过 7 项**：改成线尾直接标注，或拆成小多图。
6. **经纬度直接当平面坐标画地图**：沈阳纬度约 41.8°，经度方向 1 度只有纬度方向的 0.75 倍长，必须校正长宽比（matplotlib：`set_aspect(1 / cos(纬度))`；Plotly：`scaleanchor` + `scaleratio`）。
7. **展示个人**：图表、表格、报告里不出现完整 IMSI 或手机号；个例只显示尾号，且只在教学需要时使用。

## 6 数字

- 整数用千分位：2,037；不写 2037。
- 百分比：一般取整（40%）；比较接近的数保留一位（15.0% vs 11.2%）；很小的值自动多保留位数（0.01%，不写 0.0%）。
- 单位写全：“人”“分钟”“公里”；时长超过 2 小时改用小时。
- **删失的数写“至少”**：停留时长中位“至少 2.7 小时”。
- **识别率写出来**：“能识别过夜地的访客（占 62%）中……”。

## 7 隐私与模拟数据

- 少于 5 人的格子在 ADS 层就已置空（含互补抑制）；图上显示为“<5 人”或空白，不能用其他数据反推补回。
- 模拟分区出的图必须打水印（`watermark(fig)`），平台显示红色斜纹横幅；分析报告不得使用模拟分区。

## 8 文件与格式

- 命名：`D{天}_{序号}_{中文主题}.png`，例如 `D14_03_联动矩阵.png`；报告图 `Q01_…`（质量）、`C01_…`（清洗）、`A01_…`（分析）。
