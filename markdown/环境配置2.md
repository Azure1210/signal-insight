# 环境配置

1. 打开项目，配置解释器： 不同的项目可以有不同的解释器

2. 在single-insight这个根目录建立： src目录， 注意src是个目录

3. 接着在src目录：建立python软件包： single_insight

4. 最后在根目录建立：pyproject.toml文件里面的内容直接复制

   ```toml
   [project]
   name = "signal-insight"   # 发行名：pip 用，习惯用短横线
   version = "0.1.0"
   description = "用于快速构建和分析信令数据" # 包的描述
   readme = "README.md" # 项目的说明文件
   requires-python = ">=3.12"
   license = "MIT"
   authors = [{ name = "Azurekite", email = "sx12101184@qq.com" }]
   keywords = ["信令数据分析", "pandas", "matplotlib", "teaching"]
   classifiers = [
       "Programming Language :: Python :: 3",
       "Operating System :: OS Independent",
       "Intended Audience :: Education",
       "Environment :: Console",
   ]
   
   dependencies = [
       "pandas>=3.0.6",
       "numpy>=2.5.3",
       "matplotlib>=3.11.2"
   ]
   
   [build-system]
   requires = ["hatchling"]
   build-backend = "hatchling.build"
   
   [tool.setuptools.packages.find]
   where = ["src"]            # 包在 src/ 下面
   ```

   然后在项目的根目录打开终端，激活虚拟环境，然后安装

   ```
   python -m pip install -e . 
   
   E:\Anaconda3\envs\signal\python.exe -m pip install -e . 
   ```

   

python软件包和普通有什么区别：没什么区别，软件包里面多了一个`__init__.py`
