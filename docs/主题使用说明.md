# 主题使用说明

本文告诉你：**什么场合用哪个主题、怎么切换、出图时怎么取色**。只需要使用现有主题的同学读这一篇就够了。

- 图表本身的要求（五部分结构、配色纪律、字体合规、审图清单）见《图表规范》。
- 想新增或修改主题，见《主题扩展指南》。

---

## 1. 最短用法

notebook 第一格写一行：

```python
from signal_insight import viz, config
viz.apply_theme("business")    # 换成你需要的主题名；不写参数则用 config.THEME
```

之后照常画图，用 `viz.finish()` 收尾。颜色、字体、字号、边框风格都由主题决定，画图代码不用改。

---

## 2. 选哪个主题

| 交付物 / 场合 | 推荐主题 | 理由 |
|---|---|---|
| notebook 探索、日常出图 | `default` | 项目原配色，克制、不抢眼；未指定时就是它 |
| Word 分析报告、论文、需要黑白打印的材料 | `academic` | 色盲友好，衬线字体，灰度打印仍可读，符合期刊插图习惯 |
| 汇报 PPT、展示平台、对外宣传 | `business` | 色彩明快，无衬线字体，投影和大屏上更醒目 |
| 课件、面向非专业听众的分享 | `lively` | 与课件同一套配色，蓝色主调、粉色点睛，亲和感更强 |

拿不准时：**给专业读者看、要打印的用 `academic`；给决策者或大众看、在屏幕上展示的用 `business`。**

> **同一份交付物只用一个主题。** 一份报告里的全部图、一套 PPT 里的全部图必须同一个主题，否则"同一区域在所有图里同色"就失效了，评审时第 7 项会扣分。

---

## 3. 四个主题一览

四个主题都遵守同一套配色纪律：**灰色打底，一种颜色强调一件事，红色只表示警示，"过夜地不明"永远是灰色。** 它们的区别只在于具体色值、字体和版式手感。各角色的完整色值见《图表规范》第 2.2、2.3 节，对比效果见 `theme_preview.png`。

### 3.1 `default`：项目原配色

- **外观**：深蓝主色 #1D6FA5，橙、绿、紫、玫红、橄榄作为分类色；只保留底部轴线和水平网格，标题上方有主色短条。
- **字体**：TeX Gyre Termes + 思源宋体。
- **适合**：日常探索、组内交流。v1.4 之前的全部图都是这个样子。

### 3.2 `academic`：学术规范

- **外观**：Okabe-Ito 色盲友好色板（蓝、橙、蓝绿、紫红、天蓝、黑），四面边框，刻度朝内，不画网格，不画标题短条；警示色用朱红 #D55E00，以便和"通过"绿区分。
- **字体**：TeX Gyre Termes + 思源宋体，公式字体同为 Times 风格。
- **字号**：标题 13、副标题 10、来源行 8，比其他主题小一号，因为论文插图常缩到单栏宽度。
- **适合**：Word 报告、论文、需要打印的材料。
- **注意**：第 6 个分类色是黑色。棋盘山在这个主题下是黑线，请不要再用黑色表达其他含义。

### 3.3 `business`：商业规范

- **外观**：亮蓝主色 #2563EB，分类色拉开色相（橙、翠绿、紫、青、金），线条更粗、线端圆头，子图标题加粗，保留标题短条。
- **字体**：TeX Gyre Termes（Times 的开源替代）+ 思源宋体。
- **适合**：汇报 PPT、展示平台、宣传材料。

### 3.4 `lively`：课件活泼配色

- **外观**：来自课件 HTML 的"活泼"主题。蓝色主调 #3E8EDE、粉色点睛 #E66A8D、薄荷 #3DB29F，再接暖橙、紫、深薄荷；蓝灰色文字，线端圆头。
- **字体**：继承 business（TeX Gyre Termes + 思源宋体）。
- **适合**：课件、讲座、面向非专业听众的分享。
- **注意**：
  - 这个主题由 `themes/lively.toml` 提供，不是写在代码里的内置主题。项目根目录下必须有 `themes/` 文件夹。
  - 第 3 个分类色（中街商圈，薄荷）和第 6 个（棋盘山，深薄荷）是同色系，只靠明度区分。这两个区域出现在同一张图里时，建议用线尾直接标注区域名。

## 4. 出图时怎么取色

**原则：按语义取色，不写色值。** 写死的 `"#1D6FA5"` 不会随主题变化，换主题后这张图就和其他图对不上了。

| 想要的颜色 | 推荐写法 | 也可以 |
|---|---|---|
| 主色 / 主色浅 / 主色中 / 主色深 | `t.main` / `t.main_light` / `t.main_mid` / `t.main_dark` | `viz.MAIN` 等常量 |
| 背景对象 | `t.gray` | `viz.GRAY` |
| 警示 / 警告 / 通过 | `t.alert` / `t.warn` / `t.ok` | `viz.RED` / `viz.AMBER` / `viz.GREEN` |
| 文字 | `t.ink` / `t.muted` / `t.faint` | `viz.INK` / `viz.MUTED` / `viz.FAINT` |
| 某个区域 | `viz.AREA_COLOR["西塔"]` | |
| 某个客群 | `viz.SEG_COLOR["过夜地不明"]` | |
| 第 N 个分类色 | `t.color(N)` | |
| 连续色图 / 发散色图 | `t.cmap()` / `t.cmap("diverging")` | 不传 `cmap`，`imshow` 默认就用主题的连续色图 |

其中 `t = viz.current_theme()`。

一个完整的例子：

```python
import matplotlib.pyplot as plt
from signal_insight import viz, config

viz.apply_theme("business")
t = viz.current_theme()

fig, ax = plt.subplots(figsize=(8, 4.5))
for area in ["西塔", "太原街商圈", "中街商圈"]:
    s = hourly[area]
    ax.plot(s.index, s.values, color=viz.AREA_COLOR[area])
    ax.text(s.index[-1], s.values[-1], f" {area}", color=viz.AREA_COLOR[area], va="center")

ax.axhline(capacity, color=t.alert, lw=1, ls="--")   # 红色只表示警示
peak = hourly["西塔"].idxmax()
viz.finish(fig,
           f"西塔 {peak} 点达到峰值 {hourly['西塔'].max():,} 人",
           "10-03 每人每小时一个位置；区域可以重叠，各区域分别计数、不能相加",
           config.SOURCE_NOTE,
           "D14_01_区域客流.png")
```

### 以前的代码不用改

以前写的 `color=MAIN` 可以原样保留。切换主题时，`viz` 会把各模块和 notebook 里通过 `from ... import` 拿到的颜色常量一起换成新主题的值：

```python
from signal_insight.viz import MAIN, RED, GRAY    # 也可以 from signal_insight.viz import *
viz.apply_theme("academic")
ax.plot(x, y, color=MAIN)                         # ✅ 已经是 academic 的主色
```

`AREA_COLOR`、`SEG_COLOR`、`FONTS` 是原地更新的，也都安全。

只有下面三种写法**不会**跟着变，因为值在切换主题之前就被复制走了：

| 写法 | 为什么不变 | 改成 |
|---|---|---|
| `from signal_insight.viz import MAIN as M` | 改了名的导入不会被重绑，避免误改 | 去掉 `as`，或用 `viz.MAIN` |
| `def draw(color=MAIN): ...` | 默认参数在函数定义时就固定了 | `def draw(color=None): color = color or MAIN` |
| `c = MAIN` 后再用 `c` | 局部变量或另起名字的变量是一份拷贝 | 用的时候再写 `MAIN` |

## 5. 指定主题的三种方式

| 方式 | 写法 | 适合 |
|---|---|---|
| 代码里指定 | `viz.apply_theme("academic")` | **交付脚本**，结果不依赖运行环境 |
| 环境变量 | `SIGNAL_THEME=academic python run.py` | 同一个脚本临时换主题跑一遍 |
| 改默认值 | `config.py` 中的 `THEME = "default"` | 整个项目换默认主题 |

优先级：代码里写的主题名 > 环境变量 `SIGNAL_THEME` > `config.THEME`。

交付用的脚本（报告、PPT、平台）**请一律在代码里写明主题名**，不要依赖默认值，否则别人换个环境变量就出了另一套颜色。

## 6. 临时切换与一次出多版

`use_theme` 只在 `with` 块内生效，退出后 rcParams 和颜色常量都会恢复。适合在一个 notebook 里同时出报告版和 PPT 版：

```python
def draw_peak(t):
    fig, ax = plt.subplots(figsize=(8, 4.5))
    ...                                   # 画图代码里只用 t.xxx / viz.AREA_COLOR 取色
    return fig

for theme_name, folder in [("academic", "report"), ("business", "ppt")]:
    with viz.use_theme(theme_name) as t:
        fig = draw_peak(t)
        viz.finish(fig, title, subtitle, config.SOURCE_NOTE,
                   f"{folder}/D14_01_区域客流.png")
        plt.close(fig)
```

画图函数一定要在 `with` 块**里面**调用，并且用 `t` 或 `viz.` 取色，这样两版的颜色才会各自正确。

## 7. 按交付物的配方

### notebook

```python
fonts = viz.apply_theme()          # 用默认主题
print(fonts)                       # 确认本机实际生效的字体
```

如果打印出"⚠️ 本机没有课程用的开源中文字体"，请先安装思源字体并重启内核。**不要**改用系统自带的微软雅黑、苹方等商业字体，原因见《图表规范》第 0 节。

### Word 分析报告

- 主题：`academic`。
- 插图宽 15.4 厘米（A4 版心），建议 `figsize=(6.06, 3.8)` 左右（单位为英寸）。
- 交付时导出 PDF，或者随文件附上字体安装包。

### 汇报 PPT

- 主题：`business`，课件场景用 `lively`。
- 16:9 页面建议 `figsize=(10, 5.6)`。
- 一套 PPT 只用一个主题。

### 展示平台

- 主题：与 PPT 保持一致（`business` 或 `lively`）。
- Plotly 图的颜色从同一主题取（`viz.current_theme()` 的各属性），与 matplotlib 出图同源。

## 8. 常见问题

**Q：apply_theme 返回的字体列表里是 `Noto Sans CJK JP`，没有 SC，正常吗？**
正常。很多 Linux 机器只装了泛 CJK 合集的日文命名版，它覆盖简体字形，主题会自动识别为同一套字体。只有少数汉字（直、骨、返……）是日文写法，正式出图建议安装 SC 版。

**Q：自己在主题或 TOML 里写了 "Microsoft YaHei"，为什么报错？**
这是有意的。商业字体是合规红线，主题加载时会直接拦截。请改用思源黑体（`Noto Sans CJK SC`）。

**Q：`apply_theme("lively")` 报"没有名为 'lively' 的主题"？**
`lively` 来自项目根目录下的 `themes/lively.toml`。请确认这个文件存在（与 `signal.workspace` 同级的 `themes/` 文件夹里），然后重启内核。

**Q：切换主题后，之前画的图没有变？**
主题只影响切换**之后**新画的图。已经画好的 figure 需要重新运行画图代码。

**Q：热力图上有几条白色横线？**
那是主题的水平网格画在了图像上。画热力图时加一句 `ax.grid(False)` 即可去掉。

**Q：能不能在一张图里混用两个主题的颜色？**
不能。一张图、一份交付物只用一个主题。
